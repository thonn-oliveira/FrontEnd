O que é JavaScript?

JavaScript é uma linguagem de programação usada para tornar páginas web interativas. Enquanto o HTML estrutura a página e o CSS cuida da aparência, o JavaScript cuida do comportamento — o que acontece quando o usuário clica em um botão, preenche um formulário, etc.

Ele roda diretamente no navegador, sem precisar instalar nada. É uma das linguagens mais usadas no mundo.

💡 Curiosidade: JavaScript é a mesma coisa que Java — não é! Os nomes são parecidos, mas são linguagens completamente diferentes.

Variáveis e Tipos de Dados

Variáveis são como caixinhas que guardam informações. Existem três formas de declarar:

  • var — forma antiga, evite usar
  • let — use quando o valor pode mudar
  • const — use quando o valor não vai mudar
// Declarando variáveis
let nome = "Anthony";
let idade = 22;
const pais = "Brasil";

// Mostrando no console
console.log(nome); // Anthony
console.log(idade); // 22

Os principais tipos de dados são:

String — texto

Qualquer texto entre aspas: "Olá, mundo!"

Number — número

Números inteiros ou decimais: 42 ou 3.14

Boolean — verdadeiro ou falso

Só pode ser true ou false

Condicionais — if / else

Condicionais permitem que o código tome decisões. Se uma condição for verdadeira, faz uma coisa — senão, faz outra.

let idade = 18;

if (idade >= 18) {
    console.log("Maior de idade");
} else {
    console.log("Menor de idade");
}

No exemplo acima, como idade é 18, o console vai mostrar: Maior de idade.

Funções

Funções são blocos de código que você pode reutilizar. Você define uma vez e chama quantas vezes quiser.

// Definindo a função
function saudacao(nome) {
    console.log("Olá, " + nome + "!");
}

// Chamando a função
saudacao("Ana"); // Olá, Ana!
saudacao("Pedro"); // Olá, Pedro!

Loops — Repetição

Loops servem para repetir um bloco de código várias vezes. O mais comum é o for.

// Conta de 1 até 5
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

// Resultado: 1, 2, 3, 4, 5

O loop for tem três partes:

  1. let i = 1 — começa com i valendo 1
  2. i <= 5 — continua enquanto i for menor ou igual a 5
  3. i++ — aumenta i em 1 a cada repetição
