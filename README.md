# FrontEnd

Repositorio da disciplina de **Front End** do curso de **Engenharia de Software**.

Este repositorio reune atividades, exercicios, revisoes, provas e pequenos projetos desenvolvidos ao longo da disciplina, usando principalmente HTML, CSS e JavaScript.

## Acesso aos projetos

A pagina principal do repositorio funciona como indice dos projetos:

```text
index.html
```

Se publicado no GitHub Pages, o acesso fica pelo endereco:

```text
https://thonn-oliveira.github.io/FrontEnd/
```

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- DaisyUI
- Git e GitHub
- GitHub Pages

## Principais conteudos

### Atividades iniciais

As pastas `ativ1` ate `ativ7` contem exercicios praticos feitos durante a disciplina, envolvendo criacao de paginas, estilizacao, responsividade, uso de componentes e interacoes com JavaScript.

### Jogo Termo

A pasta `2bi/ativ_jogo_2605` contem um jogo estilo Termo, feito com HTML, CSS e JavaScript puro.

Funcionalidades:

- Tabuleiro com 6 tentativas
- Palavra com 5 letras
- Teclado fisico e teclado virtual
- Cores para letra correta, letra presente e letra ausente
- Botao para reiniciar a partida

### Lista da Semana

A pasta `2bi/Lista_da_semana` contem uma lista de exercicios separada em quatro partes:

- `exe1`
- `exe2`
- `exe3`
- `exe4`

### Provas

A pasta `2bi/provas` organiza as provas por dia:

- `Dia 1`
- `Dia 2`
- `Dia 3`

Cada dia possui suas questoes separadas em pastas proprias, facilitando o acesso e a organizacao dos arquivos.

## Como executar localmente

Clone o repositorio:

```bash
git clone https://github.com/thonn-oliveira/FrontEnd.git
```

Entre na pasta:

```bash
cd FrontEnd
```

Abra o arquivo `index.html` no navegador.

Tambem e possivel usar a extensao **Live Server** no VS Code para navegar pelos projetos.

## Como enviar alteracoes

Depois de editar os arquivos:

```bash
git status
git add .
git commit -m "Descreva sua alteracao"
git push
```
